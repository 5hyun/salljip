# 구현 범위와 데이터 게이트

## 동작하는 범위

- 과거 시점·지역·보유 현금·가정 대출·취득비·면적 조건 검색
- 취소 거래 제외, 후보별 과거/최근 가격 범위, 표본 수와 신뢰도
- 전체 후보 분포, MapLibre 지도, 반응형 후보 선택 UI
- 원금균등 대출과 월별 이자·원금·보유비를 포함한 주택 시뮬레이션
- 전세보증금 이중계상 방지, 월세와 금융자산 재투자 현금흐름
- KOSPI, NASDAQ, S&P 500, 정기예금, 정기적금 대안 비교
- 계산 엔진 출력만 설명하는 결정론적 근거 해설과 주의사항
- 전세가격지수, 전월세 거래량, 입주 예정 물량 지표
- 데이터 출처·권리 상태·기준일·계산 버전·주의사항 표시
- PostGIS 원천/정규화/정정 이력/금융자산/환율/지표/시뮬레이션/수집 실행 스키마
- Docker Compose 실행, readiness, API 입력 검증, 전역 오류 응답

## 검증 기준

- `npm run verify`: ESLint, Next.js 프로덕션 빌드, Spring Boot 테스트
- 계산 엔진: 20개 매개변수 골든 케이스와 결정성·예산 경계 테스트
- 실제 PostGIS 컨테이너에서 Flyway 초기 마이그레이션 확인
- Playwright로 데스크톱/모바일 검색, 지도, 차트, 자산 비교 확인
- 최종 브라우저 콘솔 오류 0건, 경고 0건

## 외부 데이터 게이트

매매 실거래는 국토교통부 원천을 PostGIS에 적재해 쓰며 데모 모드는 제거했다. 금융자산·시장지표 값은 아직 합성값이다. 실제 데이터 연결은 코드 결함이 아니라 아래 운영 입력이 필요한 배포 게이트다.

1. 제공기관 API 키 또는 계약 계정
2. 공개·상업 이용 및 재배포 허용 범위 확인
3. 출처 표기 문안과 보존 기간 확정
4. 지수의 배당 포함 여부, 환율 기준 시각, 예·적금 세전/세후 정의 확정

권리 검토 전에는 `INTERNAL_TEST` 소스가 공개 실데이터처럼 노출되지 않도록 UI와 API에 경고를 유지한다.
