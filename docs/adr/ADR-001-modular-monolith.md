# ADR-001: 모듈형 모놀리스로 시작한다

- 상태: 승인
- 날짜: 2026-11-17

Next.js 프런트엔드와 Spring Boot 모듈형 모놀리스, PostgreSQL/PostGIS로 시작한다. 카탈로그, 거래, 시장지표, 시나리오, 수집 모듈은 패키지 경계로 분리한다. 큐·캐시·별도 워커는 장애 및 성능 측정 결과가 도입 비용을 정당화할 때 추가한다.

핵심 리스크는 서비스 분할보다 거래 정정 이력, 건물 매칭, 시점 재현, 계산 정확성이다. 단일 배포 단위가 초기 데이터 계약과 회계 불변식 검증을 빠르게 만든다.
